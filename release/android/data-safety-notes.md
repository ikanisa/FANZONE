# Google Play Data Safety Notes

Use these notes to complete Play Console Data safety. Verify against the final production build and SDK list before submission.

## Data Collected

| Data type | Collected | Shared or sold | Purpose |
| --- | --- | --- | --- |
| Phone number | Yes | Service-provider processing only where applicable; not sold | WhatsApp OTP authentication and account recovery. |
| User IDs | Yes | Service-provider processing only where applicable; not sold | Autogenerated 6-digit FANZONE ID, Supabase user ID, support, audit, rewards ledger. |
| App activity | Yes | Service-provider processing only where applicable; not sold | Venue browsing, orders, pools, games, teams, rewards-ledger activity, eligibility, support. |
| App info and performance | Yes | Service-provider processing only where applicable; not sold | Runtime errors, stability, diagnostics, release quality. |
| Device or other IDs | Yes | Service-provider processing only where applicable; not sold | Firebase Cloud Messaging tokens and app session operation. |
| Financial info | No direct payment data | Not sold | The app does not process external payment credentials or bank/card details. |
| Location | Yes, when the user enables location | Service-provider processing only where applicable; not sold | Nearby venue discovery and venue reward discovery. The Android build declares coarse and fine location permissions, so Play Console must declare the matching location collection before submission. |
| Contacts | No | No | The app does not request contact access. |
| Photos/videos/audio | No | No | The app does not request media/camera/microphone access in the current mobile release. |

## Security Practices

- Data is encrypted in transit with HTTPS/TLS.
- Account deletion is available through support and in-app request flows where enabled.
- Rewards-ledger, order, pool, game, and audit records may be retained for fraud prevention, ledger integrity, disputes, and legal compliance.

## Important Declaration Notes

- FET is a closed-loop reward point, not cash, not an investment asset, and not withdrawable.
- The app does not contain real-money wagering or gambling mechanics.
- Prediction pools and games are free-to-play and do not offer wagers, cash prizes, monetary prizes, odds, or cash-out.
- External payment instructions may show venue-supported off-platform instructions, but FANZONE does not process payments.
- If analytics, crash reporting, or advertising SDKs are added later, update this file and the Play Console form before submission.
